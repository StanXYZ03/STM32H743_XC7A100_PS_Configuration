# FPGA-SPI 上位机

接收 STM32 通过串口发送的键盘/鼠标 HID 数据，实时显示按键与鼠标状态。

## 数据协议

- 波特率: 115200
- 串口: 8N1 (8bit数据位, 无校验, 1bit停止位)
- 帧格式: 14 字节

| 字节 | 内容 |
|------|------|
| 0 | 包头 0x55 |
| 1 | 鼠标按键: bit0=左键(1), bit1=右键(2), bit2=中键(4) |
| 2 | 滚轮: 1=向上, 0xFF=向下, 0=无 |
| 3-4 | X 坐标 (有符号 16 位小端) |
| 5-6 | Y 坐标 (有符号 16 位小端) |
| 7 | 键盘 Modifier (USB HID: bit0-7 = LCtrl,LShift,LAlt,LWin,RCtrl,RShift,RAlt,RWin) |
| 8-13 | key1~key6 (USB HID 键码) |

## 安装

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 使用

1. 连接 STM32 串口到电脑
2. 选择对应串口，点击「连接」
3. 左侧键盘与右侧鼠标会实时显示下位机传来的按键/鼠标状态
4. 按下按键时对应键高亮，滚轮滑动时有滚动动画

### 本机/串口控制仲裁

- 如果串口连续发送的数据与上一次 **不变**，则认为下位机未操控，此时可以使用本机键盘和鼠标操作界面。
- 本机控制时对应按键和鼠标按键、坐标点会以 "天蓝色" 高亮显示。
- 一旦串口数据有更新，下位机优先，界面将切换回串口控制并屏蔽本机输入。
